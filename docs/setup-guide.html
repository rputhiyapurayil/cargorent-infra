CarGoRent – Windows Setup Guide

Vehicle Rental Management System · Mini project AY 2026-27 · 11 Oct 2026

You need two programs (Git and Docker Desktop) and one command to run the whole CarGoRent system on your laptop. Plan about 45 minutes the first time, most of it downloads; after that it starts in under a minute.

Before you start

NeedMinimumWhy
WindowsWindows 10 (22H2) or Windows 11, 64-bitDocker Desktop needs WSL 2
Memory (RAM)8 GBThe 8 containers use about 3.5 GB together
Free disk space10 GBDocker images (~4 GB) plus downloads
GitHub accountInvitation acceptedThe code is in private repositories

Accept the GitHub invitations. Ramees adds your GitHub username to the 8 cargorent-* repositories. GitHub emails one invitation per repository; open each and click Accept invitation (or see them all at github.com/notifications). Without this, downloading fails with Repository not found.

Do the first run on good Wi-Fi: it downloads about 2 GB.

Step 1 – Install Git for Windows

  1. Download Git from git-scm.com/download/win and run the installer.
  2. Click Next on every screen; the defaults are fine. Keep Git Credential Manager selected (it handles the GitHub login).
  3. Check: open PowerShell (Start menu → type PowerShell) and run git --version. You should see a version number.

Step 2 – Install Docker Desktop

Docker runs MySQL, the six Java services and the website for you, so you do not install Java, Maven, Node or MySQL.

  1. Turn on WSL 2: right-click Start → Terminal (Admin) or PowerShell (Admin), run wsl --install, then restart the laptop.
  2. Download Docker Desktop from docker.com/products/docker-desktop and install it. Keep Use WSL 2 instead of Hyper-V ticked.
  3. Restart if asked, open Docker Desktop and accept its terms. You can skip signing in.
  4. Wait until the bottom-left corner says Engine running (green).
  5. Check: in PowerShell run docker compose version.

Step 3 – Download the code

The project is 8 repositories that must sit side by side in one folder. Use a short path like C:\cargorent – not Desktop, Downloads or a OneDrive folder.

Open PowerShell (normal, not Admin) and paste:

mkdir C:\cargorent
cd C:\cargorent
$repos = "infra","api-gateway","user-service","vehicle-service",
         "booking-service","payment-service","notification-service","web"
foreach ($r in $repos) { git clone "https://github.com/rputhiyapurayil/cargorent-$r.git" }

The first clone opens a browser window to sign in to GitHub; approve it once and the rest download on their own. Afterwards dir C:\cargorent lists 8 folders:

cargorent-api-gateway            cargorent-payment-service
cargorent-booking-service        cargorent-user-service
cargorent-infra                  cargorent-vehicle-service
cargorent-notification-service   cargorent-web

Step 4 – Start the app

Make sure Docker Desktop shows Engine running, then in PowerShell:

cd C:\cargorent\cargorent-infra
docker compose up --build -d

The first run takes 10–20 minutes (it builds the six Java services and the website); later starts take under a minute. It is ready when this shows 8 containers running (MySQL healthy):

docker compose ps

Wait another 30 seconds after that for the Java services to finish starting.

Step 5 – Open it and log in

Open http://localhost:3000 in Chrome or Edge.

RoleHow to log in
Adminadmin@cargorent.com / Admin@123 – lands on the Admin Dashboard
CustomerClick Sign up and register any test account
Payments are in test mode – no real money moves. Card 4111 1111 1111 1111 (any future expiry, any CVV) succeeds; 4000 0000 0000 0002 is declined.

Quick check of everything: register → search with dates → book → pay → log in as admin → approve → mark picked up → watch it move on Tracking → mark returned → Reports. The full demo script is in cargorent-infra\README.md.

View the database (MySQL Workbench)

The app must be running. MySQL is on port 3307 (not 3306, so it never clashes with XAMPP).

  1. Install MySQL Workbench from dev.mysql.com/downloads/workbench (choose No thanks, just start my download).

Working on the code (optional)

Frontend. Install Node.js 20 LTS, then:

cd C:\cargorent\cargorent-web
npm install
npm run dev

Open http://localhost:5173; it uses the Docker backend and reloads as you save.

A Java service. Edit it in IntelliJ IDEA or VS Code, then rebuild just that service (use its name: user-service, vehicle-service, booking-service, payment-service, notification-service or api-gateway):

cd C:\cargorent\cargorent-infra
docker compose up --build -d booking-service
  • Unit tests: need JDK 21 and Maven – run mvn test inside the service folder.
  • Swagger UI: localhost:8081/swagger-ui.html … localhost:8085. Add headers X-User-Id: 1 and X-User-Role: ADMIN to act as admin.
  • Postman: import cargorent-infra\postman\CarGoRent.postman_collection.json and run it top to bottom.
  • Sharing changes: in the folder you edited: git add -A, git commit -m "what you changed", git push.

Troubleshooting

ProblemFix
git clone says Repository not foundAccept the GitHub invitation for that repository and sign in as the invited account, then clone again.
docker not recognized, or cannot connect to the Docker daemonOpen Docker Desktop and wait for Engine running. Close and reopen PowerShell after installing.
Virtualization not enabled or a WSL errorRun wsl --update in an Admin PowerShell and restart. If it persists, enable Virtualization (Intel VT-x / AMD-V) in the BIOS.
port is already allocated (3000, 8080 or 3307)Stop XAMPP/Tomcat, or create cargorent-infra\.env with WEB_PORT=3001, GATEWAY_PORT=8090, MYSQL_PORT=3308, then docker compose up -d.
Website shows Cannot reach the serverServices still starting – wait a minute and refresh; check docker compose ps.
A container keeps restartingdocker compose logs <service-name> shows why; usually low memory – close apps or raise memory in Docker Desktop → Settings → Resources.
First build very slow or fails on downloadNormal on slow Wi-Fi. Run docker compose up --build -d again; finished parts are reused.
Workbench: Can't connect to MySQL server on 127.0.0.1:3307Start the app first and check MySQL is healthy in docker compose ps. Use 127.0.0.1, not localhost.
Admin login fails / want a clean demodocker compose down -v then docker compose up -d (erases all data, recreates the admin and 14 seeded vehicles).
